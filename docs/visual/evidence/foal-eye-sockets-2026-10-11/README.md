# Foal eye socket surface anchors

Read-only socket-fitting reference for the current foal blend SHA-256 recorded in `foal_eye_socket_anchors.json`. The front and both side views reproduce `/tmp/foal_closeup.py` at 1200×900 with orthographic scale 0.72 and focus `(0.57, 0, 1.29)`. Each selected pixel was ray-cast onto the visible evaluated `Body`; all four hits are recorded with face index and surface normal.

Coordinates identify points inside the visible sculpted socket recesses. They are surface fitting anchors, not final eyeball centers. Front-view image-left is horse-right (-Y); side-near is horse-right and side-far is horse-left. Red dots in the proof renders show the picked points. These anchors do not modify the builder or asset.
