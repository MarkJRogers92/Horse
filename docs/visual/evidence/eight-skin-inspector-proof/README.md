# Optional eight-influence GLB inspection proof

This scratch package validates `inspect_glb(..., max_skin_influences=8)` without changing production defaults or assets. The default remains four influences; the only valid explicit limits are integer 4 and 8. Combined skin weights are checked against the existing per-vertex normalization tolerance, joint indices are checked against attached skins, and no geometry, descriptor, morph, or rig checks were relaxed.

The final retained Blender run used Blender 5.2.1 LTS in background factory mode with auto-execution disabled. It inspected the frozen Light, Stock, and foal production GLBs using the default four-influence limit while allowing their existing clips. It also rejected the anatomically rejected FLOAT8 Light diagnostic at the default limit, accepted it at explicit limit 8, and rejected eight malformed scratch copies (unpaired set, count mismatch, wrong vector type, unsupported component type, negative weight, non-finite weight, out-of-range joint index, and unsupported set 2). The unsupported limit 6 was rejected. See `report.json`, `stdout.log`, `stderr.log`, `exit_code.txt`, and `commands.txt` for retained outputs. `attempt-1-*`/`attempt-2-*` preserve harness correction history; only `exit_code.txt` and `report.json` describe the final passing run.

The diagnostic remains an anatomically rejected numerical fixture. This proof adds no anatomy, motion, exporter, Godot-renderer, or production-promotion acceptance. Production GLBs and the source diagnostic were read only; malformed files are generated under `malformed/`.
