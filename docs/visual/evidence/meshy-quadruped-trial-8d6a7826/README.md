# Isolated Meshy Quadruped Walk diagnostic

This package records a candidate-only inspection of the unmodified `quadruped-walk.glb` (SHA-256 `8d6a78260e5b911cb0a27eafd2c1482bec718548b4dc97eeff3a22e1b6d9a8ba`). Blender 5.2.1 LTS imported only that Walk GLB into a factory-startup scene. The saved inspection Blend retains the imported mesh, armature, skinning and action, with one uniform parent scale applied for camera framing. The factor (78.003547) was estimated from pre-parent bounds before an explicit scene update; bind-pose height was not verified. The reported ~1.56 m dimension is the imported, animated action-frame-0 evaluated state, not a bind-height measurement.

The four selected mesh regions are candidate hoof regions only: vertices with weight sum >=0.05 from each named four-bone leg chain, then the lowest 10% by action-frame-0 evaluated geometry Z. The vertex indices and bounds are recorded in `report.json`. This selection has not been validated as the actual hoof sole or planted-contact area.

For a limited motion diagnostic, each candidate region's p05 point was sampled at 61 evenly spaced times over the imported 1-second action. A band equal to 2.5% of sampled mesh height (about 39 mm) above the sampled global mesh minimum was used to count proximity samples. The resulting candidate-region proximity durations were 0.600/0.550/0.450/0.167 s for hind-left/hind-right/fore-left/fore-right. Root-relative horizontal path accumulated within those proximity samples was 0.683/0.642/0.520/0.221 m. These are proximity and relative-path measurements only: they do not establish ground contact, a planted stance, or actual world-space hoof sliding. No accepted forward-speed contract was available. Root net translation was zero; maximum sampled excursion was 0.0108 m.

Six camera-filling side/front/quarter renders and their contact sheet show the imported candidate at selected frames. The filenames and report fields label each view/frame. The importer-created hidden non-skinned Icosphere bone-display helper remains in the inspection Blend and is hidden from renders; it is not an exported stray mesh. A GIF was skipped because Pillow was unavailable.

A separate Native Sol CPU review independently reproduced 7.846x edge stretch at raw edge 11559/11572 at t=0.10 s. That remains a raw-source rejection finding. Earlier scale/bind-mismatch and exported-stray-Icosphere conclusions were withdrawn as importer/inspection interpretation errors. This package does not repeat the all-edge sweep and does not establish gait suitability or production acceptance.

`report_observed_original.json` preserves the raw report emitted by the successful run. `report.json` only corrects labels and interpretation; it uses the same captured samples and records the original report hash. No scene, geometry, animation or contact computation was rerun for the wording correction. The failed first invocation and successful but misframed intermediate run remain in the scratch `attempt-1/` and `attempt-2-pre-camera-fix/` directories; only the final corrected run is packaged here. Final exit is 0 (`exit_code_final.txt`).
