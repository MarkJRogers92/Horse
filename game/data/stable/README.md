# Foaling sandbox example

`foaling_demo.clvr` is a previously committed sandbox conception used by the separate **Foaling demo** slot in the text-based stable management screen. Loading it never replaces the normal management slot, and repeated opening loads the demo's own saved progress. The game embeds this file in its C# assembly as `Cloverbrook.Game.Stable.FoalingDemo`, so the loader does not depend on a loose file or a future platform export's resource filters.

The file was written by the unmodified v2 codec at `b541bc470e78e1c52374096d1f158545c0d9c1ea`, using the genuine `old_conception_v1.clvr` fixture. Its historical headless-test conception, offspring identity, phased genome, parent links, appearance/development seeds, recorded capacity windows and all four random streams are preserved. Only the sandbox opening funds (500 coins) and current adult names (Juniper and Maple) were changed; historical parent snapshots remain intact. The fixture starts at calendar day 10 with 450 coins after its already recorded conception fee, and birth is planned for day 14.

This is test-derived example data. Its conception originally used a TEST-ONLY coat-support fixture. It is not a release approval, a new breeding command, or a bypass of the real live catalog guard. The management screen does not render this horse. Full playable breeding planning and facility capacity management remain separate packages.
