# Stable yard props

Twelve byte-identical GLBs selected from `art/collections/stable-yard-2026-11-11/models/` for the runtime game. They are reused by `scenes/world/StableYard.tscn`, instantiated by `Sets.Stable()` in the menu, stable and viewer. The standalone collection remains the source and contains provenance, actual costs, dimensions and review notes.

All props use their prepared metre scale and ground origin. The grooming case rests on the 0.55 m tack trunk. They are scenery: this integration adds no care/inventory actions, collisions, riding or save data. The horse's bounded walking route stays clear. Only selected resources are copied into the game to avoid exporting all 30 assets.
