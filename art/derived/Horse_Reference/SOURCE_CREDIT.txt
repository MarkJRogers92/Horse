This package is an adaptation of that existing model. It is not represented
as a wholly newly sculpted model. New organization, PBR materials, separate
hooves, normalized posing rig and rendered reference views were prepared for
this request. No paid assets or generation services were used.
The source model remains preserved separately; the user's Horse repository
was inspected read-only and was not edited, committed, pushed or integrated.

Game adaptation: neutral coat materials and procedural mask/UV contract.
Foal: regional juvenile deformation of this same authored mesh; short mane and tail.
Original art/reference/Horse_Reference package remains intact.
Both derived rigs are basic FK with no animation clips.
